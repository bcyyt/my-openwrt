NAT 模式
转发

关总开关会把网卡队列、CPU、PPPoE 队列、GRO、积压和分载恢复默认。NAT 模式单独生效。保存后立即生效，不断 PPPoE，不改 wan2 / IPTV。

启用转发优化

总开关。关掉后下面几项不再套用。

网卡队列绑定

IRQ/XPS 按队列绑核。PPPoE 物理口 RPS 打到全部 CPU，其它口关 RPS 走 RSS。

CPU 性能模式

全部 CPU 用 performance，降低小包突发爬频延迟。

软件流量分载

减轻 conntrack 转发开销。家用建议关掉，开了状态监控会少计客户端流量。

PPPoE 发送队列

pppoe-wan 的 txqueuelen 从 3 提到 1000，突发上传少卡住。

UDP GRO 转发

打开 rx-udp-gro-forwarding，降低 QUIC / IPTV UDP 转发 CPU。

加大接收积压

netdev_max_backlog 从 1000 提到 4096，小包突发少丢。

NAT1 同一内网端口对所有目标用同一公网端口，适合游戏联机，需要 nft_fullcone。NAT3 是默认 masquerade。NAT4 按目标换端口，入站更严。与总开关无关。软件分载可能让锥形 NAT 不准。

DHCP

地址池、租期和终端 DNS。保存后重载 dnsmasq，不断 PPPoE。

启用 DHCP

给 LAN 终端发地址。关掉后终端要自己设 IP。

按顺序分配

从地址池最小 IP 依次发放，方便按接入顺序认设备。关掉则按 MAC 哈希。

DHCP 邻居

过期租约会从列表拿掉。绑定静态 IP 立刻重分配；终端若仍握着旧地址，续租或重连即可拿到新 IP。

自动清理过期邻居

按上面的秒数定时执行。只删 FAILED 和已不在租约/静态绑定里的残留 ARP。REACHABLE 和当前仍在用的租约/静态 IP 保留。

在线设备

绑定、取消、添加静态马上生效，不用再点保存。

DNS

跟随运营商时用 WAN 拨号拿到的 DNS，不写 223 / 114。
